# 接入既有项目技能

保留既有专业技能的文学、代码或研究规则。只在“交稿 / 项目恢复 / 状态核对”入口增加路由提示：

> 涉及本地执行与 dot 审核交接时，使用已安装的 `local-dot-handoff`；分别确认发送、完整核收、内容审核与授权采用。完整材料留在约定入口，版本和冻结范围随回执返回。本地主动读取审核结果的备用方式只在该读取链路已验证可用时采用。若该技能不可用，明确说明并遵循本项目当前交接约定，不自行创建替代项目或绕过权限。

这段提示只负责发现通用方法，不替代原专业审稿标准。具体项目身份与私人入口保存在用户授权的项目资料中，不写入公共技能。更新技能后，核对资源引用、实际安装状态与目标端是否能发现；一个端安装成功不代表所有端已经自动更新。
